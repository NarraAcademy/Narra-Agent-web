## 关于 Narra Agent

Narra Agent 是一个基于人工智能的加密货币投资助手，专注于为投资者提供实时市场分析、智能投资建议和深度区块链生态洞察。

### 核心功能

- **🤖 AI 驱动的市场分析**：利用先进的机器学习算法分析加密货币市场趋势
- **📊 实时数据追踪**：监控 50+ 主流区块链网络的链上数据和市场动态
- **💡 智能投资建议**：基于风险评估和市场情绪提供个性化投资策略
- **🔍 深度研究报告**：涵盖新兴项目、DeFi 协议和 NFT 市场的专业分析
- **⚡ 即时行情预警**：关键市场事件和价格波动的实时通知

### 支持的区块链生态

Narra Agent 覆盖所有主流区块链网络，包括但不限于：

- **Layer 1**：Bitcoin, Ethereum, BNB Chain, Solana, Polygon, Avalanche
- **Layer 2**：Arbitrum, Optimism, Base, zkSync
- **DeFi 生态**：Uniswap, PancakeSwap, Aave, Compound
- **新兴链**：最新的区块链技术和创新项目

## 如何使用

### 1. 注册账户

访问 [Narra Agent](/) 并使用 Google 账户或邮箱注册。

### 2. 开始对话

在聊天框中输入你的问题，例如：
- "今天加密货币市场有什么重要新闻？"
- "分析一下 BTC 的市场走势"
- "BSC 生态有哪些值得关注的新项目？"

### 3. 获取专业分析

Narra Agent 会基于实时数据为你提供详细的市场分析和投资建议。
